Рабочие координаты — правка и ноль (G10 L20 P1)
X, мм
Y, мм
Z, мм
Поля показывают рабочие координаты станка (обновляются вместе с индикатором). Введённое значение применяется по Enter: GRBL сдвинет рабочий ноль так, что текущая точка получит введённое значение. Кнопка X = 0 объявляет текущее положение нулём по этой оси (G10 L20 P1 X0 — пишется в EEPROM GRBL).
Ручное перемещение
Клавиши: ←→ — X, ↑↓ — Y, PgUpPgDn — Z. С Shift шаг ×10.
