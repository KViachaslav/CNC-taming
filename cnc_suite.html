Лазер — гравировка (G-code)✕
Режим гравировки (как в gcodeide)
«Номинал + анизотропия» — разложение старого gcodeide: get_radius() берёт a = 0.11 (по X) и b = 0.04 (по Y), поэтому зазор на сторону = for_bufferX по Y и for_bufferX + (a − b)/2 = +0.035 по X. Правка «номинал/анизотропия» пересчитывает X/Y (X = номинал + анизотропия); можно вводить X/Y напрямую — тогда берётся введённое. Шаг колец в gcodeide — border_line_width (по умолчанию 0.07). 0/0 — первый контур по границе меди. Медь объединяется по всем отмеченным слоям (S/F/повторы — из первого отмеченного). В режиме «штриховка» используется шаг по Y (расстояние между линиями), как width_lines.
S — мощность, F — скорость, повторов — по слоям

Программа G-code✕
Превью строится по строкам с X/Y и командами G0, G1. При отправке линии G1 меняют цвет на зелёный.

Поля показывают рабочие координаты станка (обновляются вместе с индикатором). Введённое значение применяется по Enter: GRBL сдвинет рабочий ноль так, что текущая точка получит введённое значение. Кнопка X = 0 объявляет текущее положение нулём по этой оси (G10 L20 P1 X0 — пишется в EEPROM GRBL).
Ручное перемещение
Клавиши: ←→ — X, ↑↓ — Y, PgUpPgDn — Z. С Shift шаг ×10.

Карта высот (автоуровень зондом)✕
Состояние картыкарта не собрана
Сетка
Сетка задаётся в текущих рабочих координатах, поэтому сначала выставьте ноль по X/Y. Всего точек Nx × Ny — каждая точка это 4 команды, весь сбор занимает минуты. Ориентируйтесь на 3×3 … 8×8.
Зондирование
На каждую точку уходит 4 строки: G90 G0 Z… → G90 G0 X… Y… → G91 G38.2 Z-… F… → G90 G0 Z…. Нужен зонд на пине probe ($6) и состояние Idle вместо ALARM. Если касания нет в пределах хода, GRBL отдаст ALARM:5, сбор прервётся — увеличьте ход/подачу и повторите после $X.
Действия
Карта не собрана.
Замеры Z, мм—
Нажмите «Собрать карту».
Смещение точки = её Z минус максимальный Z карты: 0 — самая высокая точка, остальные отрицательные. Значит Z=0 программы нужно ставить в самой высокой точке карты (например, обнулить Z там же, где зонд дал максимум), иначе глубина уедет на разброс высот.
Вид — видимость слоёв 3D✕
Переключатели управляют слоями сцены three.js без повторного построения превью. Подпись «карта высот» появится на поверхности, когда сетка собрана и включён её показ.
